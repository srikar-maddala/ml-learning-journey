# LangChain Prompts – Research Paper Explanation Tool

A simple GenAI application built while learning **LangChain prompt engineering**.

This project uses LangChain prompts to generate explanations of research papers based on the selected paper, explanation style, and desired length.

## 🚀 Features

- Select a research paper
- Choose the explanation style
- Choose the explanation length
- Generate an AI-powered explanation
- Uses LangChain prompt templates
- Streamlit-based user interface

## 🛠️ Technologies Used

- Python
- LangChain
- Streamlit
- Ollama
- Qwen 2.5
- Prompt Engineering

## 📚 Research Papers

The application currently supports:

- Attention Is All You Need
- BERT: Pre-training of Deep Bidirectional Transformers
- GPT-3: Language Models are Few-Shot Learners
- Diffusion Models Beat GANs on Image Synthesis

## 🎯 Explanation Styles

Users can choose between:

- Beginner-Friendly
- Technical
- Code-Oriented
- Mathematical

The explanation length can also be selected:

- Short
- Medium
- Long
