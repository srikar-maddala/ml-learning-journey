# LLM Inference with Hugging Face – LFM2.5-2.6B

## 📌 Project Overview

This project demonstrates practical **Large Language Model (LLM) inference** using Hugging Face Transformers and the **LiquidAI/LFM2.5-2.6B** pretrained language model.

The goal of this project is to understand the complete workflow of loading a pretrained LLM, tokenizing prompts, generating text, and decoding the generated tokens.

## 🔄 LLM Inference Pipeline

```text
User Prompt
     ↓
Tokenizer
     ↓
Input IDs + Attention Mask
     ↓
LFM2.5-2.6B
     ↓
Autoregressive Next-Token Prediction
     ↓
Generated Token IDs
     ↓
Tokenizer Decode
     ↓
Generated Text
```

## ⚙️ Generation Parameters

### `max_new_tokens`

Controls the maximum number of new tokens generated by the model.

### Temperature

Controls the randomness of token selection.

Lower temperature generally produces more predictable output, while higher temperature allows more variation.

### Top-K

Limits token sampling to the K most probable candidate tokens.

### Top-P

Uses nucleus sampling and selects tokens from the smallest group whose cumulative probability reaches the specified probability threshold.

8. Decode the generated token IDs.
9. Experiment with different generation parameters.
